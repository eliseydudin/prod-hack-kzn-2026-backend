# ADR0001 - Выбор базы данных

- Приложение нуждается в центральном хранилище в условиях быстрой разработки.
- Другие реляционные СУБД (MySQL, MariaDB, ...) менее популярны, из-за чего имеют менее активное сообщество, т.е. меньше поддержки в случае возникновения ошибок. Также PostgreSQL имеет расширенный функционал в сравнении с ними.
- NoSQL базы данных (Redis, MongoDB, ...) лучше подходят, если проект работает с неструктуризированными данными.
- Другие типы хранилищ зачастую не имеют удобных средств взаимодействия с ними через Python (Supabase, Firebase, ...).

Решение: использовать PostgreSQL через SQLModel (wrapper под SQLAlchemy).
