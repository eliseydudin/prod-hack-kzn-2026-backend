# ADR003 - Архитектура

Итоговое решение: использовать одно FastAPI приложение, разделённое на модули.

- Для задачи с ограниченным сроком важно обеспечить быструю разработку и воспроизводимое демо.
- DDD позволяет делать масштабируемые кодбазы, но само написание кода по этой парадигме трудозатратно. Также стоит добавить, что DDD скорее ориентирован на ООП языки (Java, Kotlin и т.д.). 
- Большинство проектов на FastAPI используют монолитную архитектуру.
