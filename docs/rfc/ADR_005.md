# ADR004 - Файловое хранилище приложения

Итоговое решение: использовать RustFS.

- Идея написать собственную систему была отброшена на ранних этапах.
- Самым популярным хранилищем является AWS S3, но он требует денежных вложений.
- MinIO - главная альтернатива S3, но проект был закрыт 26 апреля 2026.
- Самой новой альтернативой является RustFS, из-за чего был выбран он.
