# ADR003 - Архитектура

Итоговое решение: использовать модульный монолит

- Для задачи с ограниченным сроком важно обеспечить быструю разработку и воспроизводимое демо.
- Большинство проектов на FastAPI используют монолитную архитектуру, что означает наличие большего количества ресурсов для обучения.
- Команда разработки лучше знакома с монолитной архитектурой.
