# ADR001 - Выбор базы данных

Итоговое решение: использовать PostgreSQL через SQLModel (wrapper под SQLAlchemy).

- Для команды разработки было важнее запустить знакомый инструмент, из-за чего был выбран PostgreSQL.
- Для взаимодействия используем SQLModel (wrapper для SQLAlchemy), т.к. он оптимизирован для FastAPI.
