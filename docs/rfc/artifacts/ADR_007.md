# ADR007 - Пуш уведомления

Итоговое решение: использовать Celery и pywebpush

- Пользователь создаёт события, которые имеют дату начала. Доп. функцией было придумано отсылать напоминания пользователю, чтобы он не пропустил отмеченные события.
- Чтобы не нагружать основной процесс, мы решили дополнительно разворачивать Celery Worker, использующий Valkey как брокера.
- Мы используем pywebpush для соответствия сервиса стандартам [Push API Mozilla](https://developer.mozilla.org/en-US/docs/Web/API/Push_API).
